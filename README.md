## 🌈ナナイロパネル Rainbow Panels
パネルを3つ並べて消す虹色パズルゲーム

[▶ ゲームを遊ぶ](https://isomissm.github.io/rainbowpanels-game/rainbowpanels.html)

### 遊び方
隣同士のパネルを入れ替えて同じ色を縦横3つ揃えよう！<br>
クリック・タップ／フリックで動かせるよ<br>
連鎖するとレインボーゲージが貯まって、BURSTカウンターが増えるよ<br>
スコアが上がると新しいパネルやモードが出現するようになるよ<br>

### 特殊パネル
- ☁️ 雲パネル：どんどん増えるお邪魔パネル
- 🌑 闇玉：カウントが0になると周囲を雲パネルに変えてしまう
- 🌈 虹玉：BURSTカウンター)が1つ増える
- 🌈 ナナイロ玉：雲パネルと闇玉を全て色パネルに変化させる！
- ☀️ 晴玉：5×5マス内にある雲パネルが赤パネルに変わる<br>
・凍っているパネルが解ける
- 🌧️ 雨玉：色パネルがランダムで青パネルに変わる
- ⚪️ 雪玉：カウントが0になると色パネルがランダムに凍ってしまう
・凍ったパネルは移動できない<br>
・色パネル隣接か手数経過で解ける
- ⚡ 雷玉：雲パネルと闇玉を一気に消せる！雲から⚡️が出てきたら雷玉の出現が近い合図！
- 🌈 プリズム：どの色のパネルとも揃えられる！
- 　　七色の玉：色パネルをたくさん消すと同色の玉が出現！7つ集めると…!?
- ⭐️ スコアが増えると「夜モード」に変わるよ！<br>
流れ星を3つ集めると昼モードに戻るよ

### その他の機能
- オートセーブ機能つき！ブラウザを閉じても続きから遊べるよ
- オプションでパネルアニメーション速度、アイコンの種類、七色の玉の形などを変更できるよ
- パネル画像を自分の好きな画像に差し替えられるよ
